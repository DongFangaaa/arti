## 4. 端到端时延

| 阶段 | 时延 |
|------|------|
| 相机抓帧 | ~30 ms（海康 GigE 软件触发） |
| 预处理 | ~5 ms（去噪+CLAHE+USM） |
| 推理 | 5~26 ms（实测） |
| 通讯上报 | ~10 ms（Modbus TCP 4 寄存器写入） |
| **总计** | **~70 ms** |

比赛要求 12 个物料 ≤ 3 分钟（速度加分），即 ≤ 15s/物料，本方案富余 ~200x。
