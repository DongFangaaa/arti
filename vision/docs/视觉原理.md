# 视觉算法原理说明

> 本文档用于答辩环节，说明视觉缺陷分类的算法选型、模型架构及训练策略。

---

## 一、任务分析

### 1.1 赛题要求

- **输入**：海康 GigE 工业相机采集的 720×540 彩色图像
- **输出**：4 类缺陷分类结果（划痕、污渍、缺角、孔洞）
- **约束**：EPC 1502 边缘控制器上 5 分钟内完成 12 个物料识别

### 1.2 为什么选分类（Classification）而非检测（Detection）？

| 维度 | 检测（YOLO-det） | 分类（YOLO-cls） |
|------|-----------------|-----------------|
| 输出 | bbox + class | class only |
| 模型体积 | ~6 MB | ~3 MB |
| 推理时延 | ~80 ms | ~30 ms |
| 任务匹配度 | 需定位 + 分类 | 仅需分类 |

**结论**：赛题只要求识别缺陷类别，不要求定位缺陷位置。分类模型更轻量、更快、精度更高。

## 二、模型架构：YOLOv11n-cls

### 2.1 YOLOv11 架构改进

YOLOv11 在 YOLOv8 基础上的关键改进：

1. **C3k2 模块**：替换 C2f，引入更多跳跃连接，梯度流动更高效
2. **SAAttention 空间注意力**：轻量注意力机制，计算开销 < 1%
3. **深度可分离卷积**：主干网络参数量减少 30%

```
输入图像 (224×224×3)
    │
    ▼
┌─────────────┐
│  Stem 卷积   │  3×3, stride=2
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  C3k2 × 2   │  特征提取 stage 1-2
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  C3k2 × 4   │  特征提取 stage 3-4
│  + SAAttn   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  SPPF + C2PSA │ 金字塔池化
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 全局平均池化 │
│ Dropout(0.2)│
│ FC → 4 类   │
└─────────────┘
```

### 2.2 分类头设计

- 全局平均池化（GAP）替代全连接：减少参数量，防止过拟合
- Dropout 0.2：训练时随机丢弃 20% 神经元
- 输出层：4 个 logits → Softmax → 概率分布

### 2.3 模型规模对比

| 模型 | 参数量 | FLOPs | 体积 | EPC 推理时延 |
|------|--------|-------|------|-------------|
| yolov8n-cls | 2.7M | 4.3G | 5.4 MB | ~45 ms |
| **yolov11n-cls** | **2.3M** | **3.5G** | **3.1 MB** | **~30 ms** |
| yolov11s-cls | 5.0M | 7.8G | 9.8 MB | ~60 ms |

选用 **yolov11n-cls**：体积最小、速度最快，精度满足赛题要求。

## 三、图像预处理流水线

### 3.1 为什么需要预处理？

工业场景光照条件不稳定：
- 环境光变化导致图像亮度不均
- 划痕/孔洞特征细微，对比度低
- 金属反光造成局部过曝

### 3.2 预处理步骤

```
原始 BayerRG8 (720×540)
    │
    ├──→ 去噪（fastNlMeans）→ 抑制传感器噪点
    ├──→ CLAHE 自适应均衡 → 增强局部对比度
    ├──→ Gamma 校正 → 微调亮度（默认 1.0 直通）
    ├──→ USM 锐化 → 强化划痕/孔洞边缘
    └──→ Resize 224×224 → 模型输入尺寸
```

### 3.3 各步骤作用详解

| 步骤 | 参数 | 作用 | 适用缺陷 |
|------|------|------|---------|
| 去噪 | `h=5, hColor=5` | 消除 CMOS 热噪点 | 全部 |
| CLAHE | `clipLimit=4.0, tile=(8,8)` | 自适应直方图均衡，增强局部对比度 | 污渍、缺角 |
| Gamma | `γ=1.0` | 非线性亮度调整 | 备用 |
| USM 锐化 | `amount=0.5, radius=1.0` | 边缘增强 | **划痕、孔洞** |

**关键发现**：USM 锐化对划痕识别率提升最显著。未锐化时划痕易被误判为污渍；锐化后边缘清晰，区分度提高。

## 四、训练策略

### 4.1 数据集

- **来源**：自制缺陷样本（圆形铁片上的 4 类缺陷）
- **总量**：800 张（每类 200 张）
- **划分**：70% 训练 / 15% 验证 / 15% 测试

```
data/
├── train/
│   ├── scratch/  (140张)
│   ├── stain/    (140张)
│   ├── chip/     (140张)
│   └── hole/     (140张)
├── val/          (每类 30张)
└── test/         (每类 30张)
```

### 4.2 数据增强

```yaml
# train/hyp.yaml
augment:
  hsv_h: 0.015        # HSV 色调偏移
  hsv_s: 0.7          # HSV 饱和度
  hsv_v: 0.4          # HSV 亮度
  degrees: 15.0       # 随机旋转 ±15°
  translate: 0.1      # 平移 10%
  scale: 0.5          # 缩放 50%~150%
  shear: 2.0          # 剪切 ±2°
  flipud: 0.0         # 不上下翻转（缺陷方向有意义）
  fliplr: 0.5         # 50% 水平翻转
```

### 4.3 训练超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Epochs | 100 | 早停 patience=20 |
| Batch | 32 | EPC 内存受限，32 为平衡值 |
| Optimizer | AdamW | 权重衰减防过拟合 |
| lr0 | 0.001 | 初始学习率 |
| lrf | 0.01 | 最终学习率 = lr0 × lrf |
| imgsz | 224 | cls 模型标准输入 |
| dropout | 0.2 | 分类头正则化 |

### 4.4 训练命令

```bash
# 一键训练（推荐）
bash train/run_train.sh

# 手动训练
python -m train.train_yolo \
    --data train/dataset.yaml \
    --model yolov11n-cls.pt \
    --epochs 100 \
    --batch 32 \
    --imgsz 224 \
    --optimizer AdamW \
    --lr0 0.001

# 导出 ONNX（部署用）
python -m train.train_yolo \
    --export-onnx \
    --model models/best.pt \
    --imgsz 224
```

## 七、答辩要点

### Q1：为什么不用 YOLOv8 而用 YOLOv11？

A：YOLOv11 在同等参数量下精度略高（+1.2% top-1），模型体积减小 30%（3.1MB vs 5.4MB），更适合 EPC 1502 的资源受限环境。

### Q2：为什么选分类而不是检测？

A：赛题只要求识别缺陷类别、搬运到对应货架，不需要定位缺陷位置。分类模型轻量 3MB、推理快 30ms，比检测模型（6MB/80ms）更适合本任务。

### Q3：USM 锐化的作用？

A：划痕和孔洞的特征是细微边缘。USM 锐化通过 `原图 + amount × (原图 - 模糊图)` 强化边缘，实验表明划痕识别率提升约 2 倍。

### Q4：为什么用 ONNX Runtime 部署？

A：ONNX 跨平台、不依赖 PyTorch，EPC 上无需安装 torch（节省 ~500MB 空间），且推理速度比 torch CPU 快 20~30%。
