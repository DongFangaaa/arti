## 整体状态机

```
                    ┌──────────────────────────────────┐
                    │          ST_INIT (0)             │
                    │   初始化：复位视觉、计数器、轴    │
                    └─────────────┬────────────────────┘
                                  │ 初始化完成
                                  ▼
                    ┌──────────────────────────────────┐
        ┌──────────▶│       ST_WAIT_VISION (10)       │◀─────────┐
        │           │ 写 HR100=1 触发视觉              │
        │           │ 读 HR110~113 等视觉返回         │
        │           └─────────────┬────────────────────┘          │
        │                         │ valid=1 AND seq>last_seq      │
        │                         ▼                                │
        │           ┌──────────────────────────────────┐          │
        │           │    ST_CALC_TARGET (20)           │          │
        │           │ 根据 defect_class 计算目标库位   │          │
        │           └─────────────┬────────────────────┘          │
        │                         ▼                                │
        │           ┌──────────────────────────────────┐          │
        │           │       ST_MOVE_AX (30)            │          │
        │           │  调用 FB_Axis_XYZ 三轴联动      │          │
        │           │  Z↑ → XY → Z↓                    │          │
        │           └─────────────┬────────────────────┘          │
        │                         │                                │
        │                         ▼                                │
        │           ┌──────────────────────────────────┐          │
        │           │       ST_RELEASE (40)            │          │
        │           │ 释放气爪/吸盘，物料落入库位     │          │
        │           └─────────────┬────────────────────┘          │
        │                         │                                │
        │                         ▼                                │
        │           ┌──────────────────────────────────┐          │
        │           │    ST_RETURN_HOME (50)           │          │
        │           │ 三轴回归 HOME 位                 │          │
        │           └─────────────┬────────────────────┘          │
        │                         │                                │
        │                         ▼                                │
        │           ┌──────────────────────────────────┐          │
        │           │        ST_READY (60)             │──────────┘
        │           │ processed_count += 1            │
        │           │  < 12: 回到 ST_WAIT_VISION      │
        │           │  ≥ 12: 回到 ST_INIT             │
        │           └──────────────────────────────────┘
        │
        │ 异常分支（class=-1 或非法）
        ▼
┌────────────────────────────────────┐
│         ST_ALARM (99)              │
│  报警码：1001=未识别 1002=非法    │
│  触发蜂鸣器/指示灯                │
│  等待人工复位                      │
└────────────────────────────────────┘
```

## 状态机转换条件表

| 当前状态 | 转换条件 | 下一状态 |
|---------|---------|---------|
| ST_INIT | 初始化完成 | ST_WAIT_VISION |
| ST_WAIT_VISION | `xResultValid=1` AND `iResultSeq>last_seq` AND `class∈[0,3]` | ST_CALC_TARGET |
| ST_WAIT_VISION | `xResultValid=1` AND `iResultSeq>last_seq` AND `class=-1` | ST_ALARM |
| ST_CALC_TARGET | 计算完成 | ST_MOVE_AX |
| ST_MOVE_AX | `bDone=TRUE` | ST_RELEASE |
| ST_MOVE_AX | `bError=TRUE` | ST_ALARM |
| ST_RELEASE | 释放完成 | ST_RETURN_HOME |
| ST_RETURN_HOME | 回归完成 | ST_READY |
| ST_READY | `processed_count < 12` | ST_WAIT_VISION |
| ST_READY | `processed_count ≥ 12` | ST_INIT |
| ST_ALARM | 人工复位 | ST_INIT |

## 寄存器映射（与 vision/config.yaml 一致）

```
HR100  xVisionTrigger   PLC→Vision  触发拍照
HR110  xDefectClass     Vision→PLC  0=hole, 1=chip, 2=scratch, 3=stain, -1=未识别
HR111  fConfidence      Vision→PLC  0~1000（×1000）
HR112  xResultValid     Vision→PLC  0/1
HR113  iResultSeq       Vision→PLC  序列号
```

## 货架布局（4 列 × 3 层 = 12 库位）

```
        列1      列2      列3      列4
      (hole)   (chip)  (scratch) (stain)
层1 [1-1]    [2-1]    [3-1]    [4-1]
层2 [1-2]    [2-2]    [3-2]    [4-2]
层3 [1-3]    [2-3]    [3-3]    [4-3]
```

放置顺序：第 1、5、9 号物料放层1；第 2、6、10 放层2；第 3、7、11 放层3；循环。

## 时间预算

| 阶段 | 耗时 |
|------|------|
| ST_INIT → ST_WAIT_VISION | <100ms |
| ST_WAIT_VISION（等待视觉）| ~30ms |
| ST_CALC_TARGET | <10ms |
| ST_MOVE_AX（三轴联动）| 1~3s |
| ST_RELEASE | 200ms |
| ST_RETURN_HOME | 1~2s |
| ST_READY | <100ms |
| **单次循环总计** | **~5s** |

12 个物料 × 5s = **~60s**（比赛要求 ≤3 分钟，远低于）
